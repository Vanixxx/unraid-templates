# Unraid templates by Vanixxx

Docker templates for [Unraid](https://unraid.net) Community Applications.

| App | What | Template |
|---|---|---|
| [owncryptofolio](https://github.com/Vanixxx/owncryptofolio) | Self-hosted crypto portfolio tracker with German tax reports; needs a PostgreSQL container | [templates/owncryptofolio.xml](templates/owncryptofolio.xml) |

Install through **Apps** in Unraid (search for the app's name). Questions and bugs: the issues of
each app's own repository.

The templates are MIT licensed ([LICENSE](LICENSE)); each app keeps its own licence
(owncryptofolio: AGPL-3.0).
